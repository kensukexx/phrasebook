使い方

📇 フレーズ一覧

カードをタップすると発音します。左右にスワイプするとカテゴリを切替、カード右下の⤢で相手に画面を見せる全画面表示になります（全画面表示では🎙️録音で自分の発音を録音し、聞き比べることもできます）。検索欄は日本語・現地語のどちらでも検索でき、🎤をタップすれば声で入力することもできます。カテゴリタブ・カード本体はどちらも長押ししてドラッグすると好きな順番に並び替えられます（カテゴリタブの「すべて」は常に先頭固定）。検索欄の上のスイッチで「通常の単語」⇄「会話パターン」のカテゴリ表示を切り替えられます。▶（聞き流し再生）の横にある速度ボタンをタップすると、設定画面を開かずに現地語スピードをその場で切り替えられます。聞き流し再生では、一覧の表示順そのものは変えずに、✓覚えた済みのフレーズだけ再生順を後回しにします（すべて表示中はその中で、カテゴリを絞り込んでいればそのカテゴリの中で最後にまとめて再生）。未習得のものを優先して聞けます。

📌 ✓ ピン留め・覚えた

カード下の📌でよく使うフレーズを固定表示、✓で「覚えた」印を付けられます。一覧上部の📌アイコンでピン留めしたものだけ、✓アイコンでまだ覚えていないものだけを表示するように絞り込めます。

＋ フレーズを追加

右下の＋ボタンから自分の言葉を手動追加できます。日本語を入力して「自動翻訳」を押すと空欄の言語がまとめて翻訳されます（設定でGeminiキーを登録していれば、カタカナ読みも自動生成されます）。「解説」欄に使い方や注意点を書いておくと、組み込みフレーズと同じように📖解説ボタンから確認できます（空欄なら解説ボタン自体が表示されません）。自分で追加したフレーズのカードには✎（編集）と✕（削除）が表示され、いつでも修正・削除できます。カテゴリ選択欄の「＋」から自分だけのカテゴリも作成でき、作ったカテゴリはカテゴリタブにも表示されます（🗑で削除も可能。削除すると、そのカテゴリのフレーズは自動で「その他」に移動します）。

🗣️ 話す（翻訳して発音）

その場で伝えたい日本語を入力・音声入力すると、画面を切り替えずにこの中で翻訳結果を表示します（Google翻訳アプリのような感覚で使えます）。入力した日本語はそのまま残るので、続けて次の一言も入力できます。🔊で発音、★でフレーズ帳に保存、⤢で大きな文字の全画面表示に切り替えて相手に見せられます。上部の言語選択でその都度言語を切替可能（一覧の表示言語とは独立）。「相手の番」ボタンを使うと、選んだ言語で相手に話してもらった内容を聞き取り、同じようにその場で日本語に翻訳して表示します（交互に一往復ずつ翻訳する会話モード）。

🎓 学習ラウンジ

AIと一緒に言い回しを深掘りするための機能で、2つのモードがあります（いずれも設定でGeminiキーの登録が必要）。📝 例文セットは覚えたい単語を入力すると、その単語を使った例文セット（用法パターン別に発音・訳付きの例文）を作ってくれます。各例文には🔤で単語ごとの意味対応も表示され、どの単語がどの日本語に当たるか一目でわかります。💬 AIに質問は「おすすめを聞く時の質問文は？」のような、単語1つに収まらない質問を自由に投げかけられるチャットで、回答に具体的なフレーズが含まれる場合はカード形式で表示され、続けてフォローアップの質問もできます。どちらのモードで作った項目も自動で保存され、新しいものから順に1つの一覧に並びます（💬のバッジでチャットの項目と見分けられます。タップすればいつでも見返せます）。表示件数は既定20件で、それより多い分は設定画面の「学習ラウンジ一覧の表示件数」で増やせます。自分で作った項目は✕で削除できます。気に入ったフレーズは★でフレーズ帳に追加でき、追加先のカテゴリはその場で選べます（他の言語欄は空欄のままなので、必要なら🌐自動翻訳で埋められます）。

📚 英単語3000

日常会話の9割をカバーすると言われる頻出英単語を、使用頻度順に学べる独立モードです。フレーズ帳のカテゴリとは別の、単語だけの学習専用の一覧です。「範囲」で500語ずつの区間を選び、単語カードをタップすると裏に日本語の意味と例文（英語・カナ・和訳）が表示されます（表・裏それぞれに🔊）。✓で覚えた単語に印を付けられ、進捗が「覚えた ◯ / ◯」で表示されます（覚えた状態はフレーズ一覧の✓とは別管理で、端末間同期の対象です）。検索は英単語・日本語の意味どちらでも可能です。2026年9月現在は最重要語300語のみを収録しており、今後のアップデートで3000語まで拡充予定です。

📷 メニュー翻訳（写真から）

レストランのメニューや街の看板を撮影すると、写っている文章をAIが読み取り、フレーズごとの読み方（カタカナ）と意味の一覧を作ります（設定でGeminiキーの登録が必要）。何語で書かれているかも自動で判定します。一覧の各項目は🔊で発音を確認できます。

🌏 日本語を学ぶ（外国人向け）

日本語を学びたい外国人の友達と一緒に使う実験的な機能です（v1）。「知っている言語」を選ぶと、その言語のフレーズがカードの表になり、タップすると裏に日本語とローマ字の読み方が出てきます（表・裏それぞれに🔊）。カテゴリ分けは今のところ無く、検索と一覧のみです。画面内の文言は英語表記のみで、メニューなど周辺は今まで通り日本語のままなので、日本語話者が操作をリードする使い方を想定しています。組み込みの309フレーズが対象で、自分で追加したフレーズは対象外です。

💱 通貨換算

日本円と現地通貨を相互に換算します。オンライン時に最新レートを取得し、オフライン時は前回取得分を使います。

⚙ 設定

読み上げ速度（現地語・日本語それぞれ）や文字サイズ、カテゴリバーの表示（1行スクロール⇄2行表示・はみ出た分は横スクロール）、学習ラウンジ一覧の表示件数（既定20件、数字を増やせばもっと表示できます）、聞き流し再生の設定（日本語も続けて読み上げるか・最後まで行ったらループするか・繰り返し回数・フレーズ間の間隔）、言語ごとの声、Gemini APIキーの登録などができます。言語の並び順は設定画面ではなく、一覧上部の言語ドロップダウンをタップして開く「言語を選ぶ」画面でハンドル「⠿」をドラッグして変更します。

☁️ 端末間の同期（ログイン方法）

  1. ツール（☰）→「☁️ 同期」をタップ
  2. 「Googleでログイン」を押す
  3. ポップアップで自分のGoogleアカウントを選ぶだけでログイン完了（新規登録やパスワード入力は不要）

ログインすると、カスタムフレーズ・独自カテゴリ・覚えた/ピン留め・学習ラウンジ・カテゴリ/言語/カードの並び順が他の端末と自動で同期されます。読み上げ速度・カテゴリバーの表示・学習ラウンジ一覧の表示件数など、それ以外の設定は端末ごとのままです。ログアウトは同じ画面から行えます。

🔑 Gemini APIキーの設定

学習ラウンジ（AIによる例文生成・AIチャット）・メニュー翻訳（写真から）には必須です。そのほか、フレーズ追加時のカタカナ自動生成や、翻訳・読み上げがGoogle翻訳側で失敗した時の予備手段としても使われます。未登録でも一覧・話す・通貨換算・日本語を学ぶなど他の機能は問題なく使えます。

  1. Google AI Studioを開く（Googleアカウントのみでよく、クレジットカード登録は不要）
  2. 「Create API key」でキーを発行してコピー
  3. ツール（☰）→「⚙ 設定」を開き、「Gemini APIキー」欄に貼り付ける

キーはこの端末にのみ保存されます（1日あたりの無料利用回数に上限あり）。
