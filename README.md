# ことばの旅券 — 言語別あいさつ帳

日本語 → 9言語(英・韓・独・ルーマニア・西・仏・越・中・葡)対応の旅行フレーズブックです。
アプリ本体は単一HTMLファイル(`index.html`)で動作し、サーバーやビルドは不要です
(オフライン起動用に `manifest.json` / `sw.js` / アイコン画像を同梱しています)。

## 主な機能

- フレーズの音声読み上げ(オンライン時はGoogle翻訳の自然な音声、オフライン時は端末のTTSにフォールバック。言語ごとに端末側の声も選択可)
- 話す(翻訳して発音): 日本語を音声かテキストで入力→今選んでいる言語に翻訳して発音、フレーズ帳への保存も可能
- 全画面提示モード(相手に画面を見せる)・筆談モード
- 聞き流し再生(ループ・間隔調整)
- 学習管理(覚えた ✓ / ピン留め 📌 / 進捗表示)
- カスタムフレーズの追加(端末に保存、自動翻訳ボタンあり)
- 音声入力検索・自分の発音の録音と聞き比べ
- 通貨換算(オンライン時にレート取得、オフライン時は保存済みレートを使用)

## オフラインでの利用

初回はネットに繋いだ状態で一度ページを開いてください(service workerがアプリ本体をキャッシュします)。
以降は電波がない状態でも起動・フレーズの閲覧・発音(端末TTS)が可能です。
スマホでは「ホーム画面に追加」しておくとアプリのように起動できます。
翻訳・Google音声・為替レート取得など外部通信が必要な機能のみ、オンライン時に限られます。

## 更新の反映

GitHub Pages で公開しています。`index.html` を編集して push すると、
約1分で公開ページに自動反映されます。
service worker はネット接続時に毎回最新版を取得してキャッシュを更新するので、
更新後にネットに繋いで一度開き直せば最新内容がオフラインでも使えるようになります。
