# ことばの旅券 — 言語別あいさつ帳

日本語 → 9言語(英・韓・独・ルーマニア・西・仏・越・中・葡)対応の旅行フレーズブックです。
単一HTMLファイル(`index.html`)で動作し、サーバーやビルドは不要です。

## 主な機能

- フレーズの音声読み上げ(端末のTTSを使用、言語ごとに声を選択可)
- 全画面提示モード(相手に画面を見せる)・筆談モード
- 聞き流し再生(ループ・間隔調整)
- 学習管理(覚えた ✓ / ピン留め 📌 / 進捗表示)
- カスタムフレーズの追加(端末に保存)
- 音声入力検索・自分の発音の録音と聞き比べ
- 通貨換算(オンライン時にレート取得、オフライン時は保存済みレートを使用)
