# ツウジル — 言語別あいさつ帳

日本語 → 9言語(英・韓・独・ルーマニア・西・仏・越・中・葡)対応の旅行フレーズブックです。
アプリ本体は単一HTMLファイル(`index.html`)で動作し、サーバーやビルドは不要です
(オフライン起動用に `manifest.json` / `sw.js` / アイコン画像を同梱しています)。

## 主な機能

- フレーズの音声読み上げ(オンライン時はGoogle翻訳の自然な音声、オフライン時は端末のTTSにフォールバック。言語ごとに端末側の声も選択可)
- 話す(翻訳して発音): 日本語を音声かテキストで入力→オーバーレイ内で選んだ言語に翻訳して発音、フレーズ帳への保存も可能(一覧の表示言語とは独立)
- 相手の番: 選んだ言語で相手に話してもらった内容を聞き取り、日本語に翻訳して表示(交互に一往復ずつ翻訳する会話モード)
- 全画面提示モード(相手に画面を見せる)・筆談モード
- 聞き流し再生(ループ・間隔調整)
- 学習管理(覚えた ✓ / ピン留め 📌 / 進捗表示)
- カスタムフレーズの追加(端末に保存、自動翻訳ボタンあり)
- 音声入力検索・自分の発音の録音と聞き比べ
- 通貨換算(オンライン時にレート取得、オフライン時は保存済みレートを使用)
- カテゴリタブは長押しドラッグで並び替え可能(「すべて」は先頭固定)
- アプリ内の「使い方」メニューに操作マニュアルを内蔵

## オフラインでの利用

初回はネットに繋いだ状態で一度ページを開いてください(service workerがアプリ本体をキャッシュします)。
以降は電波がない状態でも起動・フレーズの閲覧・発音(端末TTS)が可能です。
スマホでは「ホーム画面に追加」しておくとアプリのように起動できます。
翻訳・Google音声・為替レート取得など外部通信が必要な機能のみ、オンライン時に限られます。

## 端末間の同期（任意）

Googleアカウントでログインすると、カスタムフレーズ・覚えた/ピン留め・練習ノート・カテゴリと言語の並び順を複数端末間で同期できます
（Firebase Authentication + Firestore使用。未設定でもアプリ自体は今まで通り問題なく動きます）。
読み上げ速度など、それ以外の設定は端末ごとのローカル保存のままです。

セットアップ手順:

1. [Firebase Console](https://console.firebase.google.com/) でプロジェクトを作成
2. Authentication → Googleログインを有効化
3. Firestore Database を作成（本番環境モード、リージョンは任意）
4. Firestore の「ルール」タブに、リポジトリ内の `firestore.rules` の内容を貼り付けて公開
5. プロジェクトの設定 → マイアプリ → ウェブアプリを追加し、表示された `firebaseConfig` を
   `index.html` 末尾の `<script type="module">` 内にある `firebaseConfig` に貼り付ける

`firebaseConfig` の値は秘密情報ではありません（アクセス制御はFirestoreのルール側で行うため、
クライアントコードに埋め込んでも安全です）。未設定のままでも同期メニューはその旨を案内するだけで、
他の機能には影響しません。

## テスト

`tests/` にPlaywrightベースの自動テストがあります(アプリ本体はテスト不要でそのまま動きます。テストは別ツールとして分離)。

```bash
npm install
npx playwright install chromium webkit
npm test              # 全テスト実行（chromium・mobile/webkitの2構成）
npm run test:data     # データ整合性チェックのみ（ブラウザ不要・数秒で完了）
npm run test:ui       # Playwrightのインタラクティブ UI で実行
```

`node tests/data-integrity.test.js` は `index.html` 内の158フレーズ全件が9言語分そろっているか等を検証します
（数字・曜日カードが英語だけ入っていて他言語で消えていた不具合の再発防止）。
GitHub Actions (`.github/workflows/test.yml`) で push・PR時に自動実行されます。

## 更新の反映

GitHub Pages で公開しています。`index.html` を編集して push すると、
約1分で公開ページに自動反映されます。
service worker はネット接続時に毎回最新版を取得してキャッシュを更新するので、
更新後にネットに繋いで一度開き直せば最新内容がオフラインでも使えるようになります。
